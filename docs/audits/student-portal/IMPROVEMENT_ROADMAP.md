# Improvement Roadmap

## 1. Fix immediately

1. Add bounded timeout and explicit idempotent retry UI for learning evaluation requests.
2. Keep the integrated QA harness fail-fast check for the Edge Functions runtime and run the stabilized full browser suite in CI.
3. Define and test the password-recovery policy.
4. Add axe plus focus/error-announcement checks to login and the learning activity.
5. Build golden activities for every currently supported answer type before claiming broad mathematics trust.

## 2. Improve before the next product demonstration

1. Simplify the dashboard's first viewport to one “Do this next, because…” action.
2. Add a plain-language explanation of mastery versus school marks.
3. Show the learner's evidence change and next reassessment date on activity completion.
4. Rehearse the demo from a clean local reset and include Edge Functions in the startup checklist.
5. Verify Chromium at 1440, 768 and 390 px with console/network failure collection; add Firefox/WebKit smoke coverage.

## 3. Implement in the next development phase

1. Connect diagnostic evidence, targeted practice, delayed reassessment and progress narration across routes.
2. Expand reviewed CAPS content across Mathematics, Mathematical Literacy and Physical Sciences.
3. Give tutors an evidence brief showing misconception, attempts, assistance and recommended intervention.
4. Give guardians plain-language progress trends without exposing raw/private response data.
5. Add poor-network and offline-safe behavior for answer/submission ambiguity.

## 4. Longer-term product opportunities

1. Longitudinal concept maps based on retained evidence, not points.
2. Tutor-authored interventions using validated templates and controlled answer schemas.
3. Cohort-level misconception trends with small-group privacy suppression.
4. Learner reflection prompts tied to evidence and confidence calibration.
5. Formal classroom/usability research with Grade 8–12 learners and tutors.

## Success measures

- Learners identify the next action and reason in under ten seconds.
- No ambiguous duplicate or lost submission under retry/network tests.
- Every approved question type has independently reviewed positive and counterexample cases.
- Increased delayed-reassessment success, not merely activity completion.
- Tutors can explain a recommendation from traceable learner evidence.
