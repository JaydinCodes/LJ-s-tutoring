# Golden Demo Learner

Lethabo Mokoena is a synthetic Grade 9 Mathematics learner at Project Odysseus Demo School. Her formal school results are Algebraic Expressions (62%), Equations (68%), Geometry (74%), and Graphs (71%). These remain school-result records, separate from learning mastery.

Her learning progress begins with Like terms as strong understanding, Distributive property and Linear equations as making progress, and Difference of Two Squares as starting. A real open recommendation targets `G9.ALG.FACTOR.DOTS` and resolves to **Difference of Two Squares Practice**.

## Demo data created

- Synthetic learner account: `lethabo.mokoena@example.com`, Grade 9.
- Four formal Mathematics school-result records and one targeted published assignment.
- Persisted learning states backed by seeded attempt evidence, including secure prerequisite skills for Difference of Two Squares.
- Two independent historical incorrect Difference of Two Squares responses matching `DOTS_AS_SQUARE_OF_DIFFERENCE`: `(x - 5)^2` (confidence 4) and `(y - 7)^2` (confidence 3). The resulting state is `suspected` under the normal evidence rules.
- An open `contrasting_examples` recommendation for Difference of Two Squares, with `REPEATED_MISCONCEPTION`, `PREREQUISITES_SECURE`, and `TARGET_SKILL_NOT_SECURE` supported by the seeded state.
- A four-question activity and its stage records, all targeting `G9.ALG.FACTOR.DOTS`.
- A real `DOTS_AS_SQUARE_OF_DIFFERENCE` misconception taxonomy record and question-version relationship.

The reset starts the activity with no answers recorded. The incorrect and corrected attempts in the pitch are generated by the normal learner submission flow.

## Local rehearsal procedure

Run this against the local Supabase stack only:

```powershell
npm run supabase:start
npm run supabase:reset
npm run demo:reset:local
npm run dev
```

Then:

1. Sign in as `lethabo.mokoena@example.com` with the local fixture password `ProjectOdysseus!23`.
2. Execute the documented answers below.
3. Open Progress and confirm the persisted state.
4. Run `npm run demo:reset:local` again before the next rehearsal.

The reset refuses non-local Supabase URLs, seeds the synthetic Lethabo account, and invokes a service-role-only reset RPC. It restores the incomplete activity, baseline evidence/mastery, school results, recommendation, and dashboard assignment. It does not expose a learner-accessible reset route.

## Reliability contract

- Authentication: the reset script creates or repairs the local synthetic account.
- Dashboard and routing: the open persisted recommendation resolves to an approved activity with the matching target skill.
- Evaluation: the deterministic evaluator marks `(x - 5)^2` incorrect and detects `DOTS_AS_SQUARE_OF_DIFFERENCE`; `(x - 5)(x + 5)` is correct.
- Retry: activity progress only advances after a correct evaluated attempt. Incorrect evidence is never overwritten.
- Completion and progress: completion, mastery and recommendations use existing persisted functions and records; no learner-facing answer key is returned by the question-display RPC.
- Refresh persistence: attempts and activity progress are database-backed.
